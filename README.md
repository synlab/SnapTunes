## Setup Instructions
1. Clone the repository
2. Install dependencies in both `client` and `server` folders
   -  `cd client && npm i` and `cd client && npm i`
3. Start the backend server (`npm start` in `server` folder)
4. Start the frontend client(`npm run dev` in `client` folder)
5. WIP

## Tech Stack

- **Backend:** Express.js (Node.js)
- **Communication:** Socket.IO (WebSockets)
